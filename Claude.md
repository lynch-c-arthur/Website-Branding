# Website Branding Project Guide

## Project Overview

A static personal brand website for Arthur Lynch.

## Build & Development

- **Local Preview:** Since there is no build step, simply open `index.html` in a browser or use the "Live Preview" extension in Antigravity.
- **Assets:** - CSS is located in `/css/style.css`
  - JavaScript is in `/js/main.js`
  - Images are in the `/images/` folder

## Coding Standards

- **HTML:** Use semantic tags. Ensure all pages include the standard navigation found in `index.html`.
- **CSS:** Maintain the branding defined in `style.css`.
- **Images:** Always use descriptive `alt` tags for headshots and OG images.

## Deployment

- The site is configured for GitHub Pages (indicated by the `CNAME` file).
- Deploy by pushing changes to the `main` branch.
